# Naming scheme

- this is "dosbox-automation", exactly written in this convention.
- this repo is VorticonCmdr's fork of upstream dosbox-automation/dosbox-automation.
  upstream uses "da<release-number>" as its own version suffix; this fork uses
  "vc<release-number>" instead, so a version string is never mistaken for an
  upstream release.

# Versioning guide
- version numbering is upstream base version dash "vc" release number.
  example: base is 0.84, our release version is 1 -> 0.84-vc1

# full product name
- following the previous instructions, an example full product name is 
    dosbox-automation 0.84-vc1
